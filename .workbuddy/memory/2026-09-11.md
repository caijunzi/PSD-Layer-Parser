- 后果：在 Bash 里 `npm install` 必挂（npm 靠 PATH 解析 node.exe → 拿不到 → 零流量挂死）；但 `pip install` 之前能成功，是因为用了**绝对路径 python.exe** 绕开了坏 PATH

- **禁止**：在 WorkBuddy Bash 工具里执行任何 `npm` / `npm.cmd` 安装命令（必踩坑）
