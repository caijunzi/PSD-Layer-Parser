## 1. 问题定义

### 1.1 需求与现状差距

原始需求：金地水墨山水（Nagasawa Rosetsu《金地山水六曲》约 1795，MET 公共领域，4000×1952）
→ 大幅面分层 PSD，**一切可识别类别各自一层、边界干净**。

| 需求 | 状态 |
|---|---|
| 大幅面（16K @100–300 PPI） | ✅ 已达成 |
| 制版合规（CMYK/ICC/TAC） | ✅ 已达成 |
| **对象级语义层：强边界对象**（印章/题跋/人物/建筑/雁群/孤石） | ✅ **6/6 达成**（SAM 管线，边界干净） |
| **对象级语义层：无边界水墨元素**（远山/水流/松林/峭壁） | ❌ **0/4**（SAM 掩模弥散 74–75%，被弥散门拦截，内容留底板无独立层） |

### 1.2 根因：两类元素需要两种分割原理

| 元素类型 | 例子 | 图像特性 | 适配的分割原理 |
|---|---|---|---|
| **强边界离散对象** | 印章、人物、建筑、雁 | 封闭轮廓、与背景色相差异大 | 提示词实例分割（SAM2）——**已验证有效** |
| **无边界晕染场** | 远山淡墨、水波纹、松林碎笔 | 墨密度连续渐变、无闭合轮廓 | **墨密度场阈值/带分割**——密度 D=−ln(T) 对晕染强度天然敏感 |

SAM 对第二类产出全画布碎片掩模（外接框覆盖 74–75%），是模型原理性局限，prompt 调优无法根治。
用户早期 k-means 密度分解路线（14 区域/16 层 549MB）验证了密度场对晕染元素的区分力，
其缺陷（对象跨层/打碎）仅在"**只用密度**"时出现。

### 1.3 方案一句话（v0.9 修正）

**语义管对象、密度管精修**：SAM 继续负责全部强边界对象（已达成）；
密度场作为 **SAM 弥散掩模的精修通道**（`refined = SAM掩模 ∩ D>floor + 形态学`），
把"方向对但弥散"的掩模修成贴合墨迹的干净层；
两类掩模互斥合并，弥散门与 semantic_coverage 作为统一质量与披露机制。

> **§6 原型实测修正**：原 v0.9 设想的"密度带独立切割层"**验证不通过**——
> 单带切割产生密度等值区而非语义对象（04D 带抓到树冠淡墨与雁群而非远山；
> 低密度带无法区分淡墨与金地纹理噪声）。密度场的正确角色是 SAM 的精修后验，
> 详见 §9 实测结论。

## 2. 密度场定义（检测分支专用）

```
T = gray(img) / blur(gray(img), k=201)          # 平场归一化：局部金地底色估计
D = -ln(clip(T, 0.02, 1.0)) / ln(50)            # 归一化墨密度，0=纯金地 1=浓墨
```

- **R2 合规**：密度场仅用于掩模检测分支，绝不写回输出像素（与现有照度平场归一化同一约束）。
- **RK-16 合规**：密度计算是确定性算子（无随机源），不破坏逐像素复现。
- 计算在**源分辨率**（4000×1952）上完成，掩模随现有流水线统一超分。

## 3. 密度带类配置（SSOT：preset 新增 `density_band_classes`）

```json
"density_band_classes": [
  {
    "name": "04D_远山淡墨晴岚_Distant_Soft_Mountain",
    "density_min": 0.08, "density_max": 0.35,
    "region": [0.00, 0.03, 1.00, 0.42],
    "region_note": "上带：远山只可能出现在画面上部",
    "min_blob_area_px": 600,
    "morph_open": 3, "morph_close": 9
  },
  {
    "name": "05A_前景寒林枯木_Foreground_Barren_Trees",
    "density_min": 0.35, "density_max": 0.85,
    "region": [0.10, 0.22, 0.62, 0.88],
    "min_blob_area_px": 400,
    "morph_open": 3, "morph_close": 7
  }
]
```

字段语义：

| 字段 | 含义 | 跨图稳定性 |
|---|---|---|
| `density_min/max` | 该类元素的墨密度带（晕染浓度区间） | **品类级稳定**（同一画派的浓淡程式） |
| `region` | 画幅区域先验（归一化 x0,y0,x1,y1） | **构图级**——同一构图的屏风系列稳定；构图大变需更新（比 prompt 重调可控：区域框是几何直觉，prompt 是语义赌博） |
| `min_blob_area_px` | 连通域面积下限（碎片过滤） | 品类级稳定 |
| `morph_*` | 形态学核（开去碎片/闭连枝干） | 品类级稳定 |

**与 ai_semantic_classes 的关系**：`density_band_classes` 是**独立补充段**，不替换语义类。
配置在 `density_band_classes` 中的类**不再进入 SAM 语义类列表**（由 preset 加载器自动排除，避免双路重复）。

## 4. 管线集成

### 4.1 处理顺序与互斥

```
第 1 步（现有）  SAM 语义分割 → 强边界对象掩模
第 1.5 步（新增） 密度带分割   → 无边界元素掩模
                   ├─ 输入：密度场 D + 每类 (band, region)
                   ├─ 掩模 = (D∈[min,max]) ∧ region框
                   ├─ 形态学清理 → 连通域面积过滤
                   └─ 互斥：减去全部 SAM 已产出对象掩模（对象优先，防止重叠双算）
弥散门（现有）    统一检查两路产出（密度带层 bbox ≤ region框，天然 < 50% 不会被误杀）
第 2 步起（现有） 深度排序 / 补全 / 超分 / 组装 —— 不感知来源差异
```

### 4.2 与弥散门的集成点

| 场景 | 行为 |
|---|---|
| SAM 类弥散（如 04A/04D/05A 从语义类移除前） | 弥散门照常拒绝（既有机制） |
| 密度带类产出 | **过同一弥散门**；region 框面积设计 ≤ 50% 画布，正常不会触发 |
| 密度带产出后仍弥散（配置错误/异常图） | 同样拒绝并进 semantic_coverage.rejected —— 机制兜底，不留静默污染 |

### 4.3 与 semantic_coverage 的集成点

`semantic_coverage` 扩展两个来源标记（向后兼容，只加字段不改结构）：

```json
"produced": [
  {"name": "05A_前景寒林枯木_Foreground_Barren_Trees",
   "source": "density_band",            // 新增：sam | density_band | rule
   "density_band": {"min": 0.35, "max": 0.85, "coverage": 0.143}}
],
"rejected": [
  {"name": "05A_...", "reason": "...", "recovered_by": "density_band"}  // 新增：被 SAM 弥散门拒后由密度带恢复
]
```

调优者从 manifest 一眼看到：哪些类走 SAM、哪些走密度带、哪些 SAM 失败被密度带救回。

### 4.4 落点（代码）

| 文件 | 改动 |
|---|---|
| `engine/core/density_field.py`（新） | 密度场计算 + 密度带掩模生成（纯函数，可单测） |
| `engine/schemas/presets.py` | 加载 `density_band_classes`；SAM 类列表自动排除其中的 name |

## 5. 可复用性与自适应（回应"换图是否失效"）

| 层级 | 机制 | 跨图稳定性 |
|---|---|---|
| 密度带（浓淡区间） | 画派程式（江户金地屏风的墨法） | 品类内稳定 |
| region 框 | 构图先验 | 同构图系列稳定；新构图需更新——**但更新是"画框挪位置"，不是"语义赌博"** |
| **校准工具**（新增） | `scratch/calibrate_density_bands.py`：对金标准图自动分析密度直方图 → 推荐带边界与区域框（直方图峰谷检测），人工确认后写入 preset | 把"手调阈值"变成"工具推荐 + 人工确认" |
| 金标准回归 | 每品类固定标准图 + 期望层结构，preset 改动跑回归 | 防配置漂移（今天 V2 对比的固化） |

诚实的局限：**region 框仍是构图先验**——遇到构图完全不同的图（如全景竖轴）需要更新 region。
但两类元素的性质决定了：对象类 prompt 与构图无关可复用；氛围类无法完全免配置，
**能做的是把配置从"逐图调 prompt"降级为"品类级调 region 框 + 工具辅助校准"**。

## 9. 原型实测结论（2026-09-11，v0.9 验证记录）

### 9.1 密度场公式（实测修正）

```
G = percentile(gray, 88)                    # 全局金地参考（p88≈0.827）
D = -ln(clip(gray/G, 0.01, 1)) / ln(50)     # D ∈ [0, ~0.87]
D_s = GaussianBlur(D, sigma=4)              # 抑金地纹理噪声（保晕染结构）
```

**实测教训**：局部平场（blur 大核做底色估计）会把**大面积浓墨区内部漂白**
（峭壁中心 bg≈gray → D≈0）——金箔材质全画布统一，金地参考必须取全局分位数。

### 9.2 实测分布（source_4000.jpg）

D 分位数：p50=0.048 / p75=0.224 / p90=0.224 / p95=0.254 / p99=0.378 / max=0.871；
D>0.15 占 33%（水墨内容量级），D>0.35 占 1.5%（浓墨主体）。
密度热图空间结构正确：金地≈0、墨迹 0.15–0.4、绫边最高（region 排除即可）。

### 9.3 三层精修实验结论

公式：`refined = SAM弥散掩模 ∩ (D_s > floor) + close(9) + open(3)`，floor ∈ {0.05, 0.08, 0.12} 扫描。

| 层 | raw 弥散 | floor=0.12 精修结果 | 判定 |
|---|---|---|---|
| **04A 峭壁** | bbox 74.4% | **bbox 16.4%，橙色掩模精确贴合岩壁皴法** | ✅ **可产出独立层**（floor=0.12） |
| 04D 远山 | bbox 74.5% | 与 04A 高度重叠；远山本体 D≈0.05–0.1 与金地噪声同量级未被抓到 | ❌ 不可产出（SAM 掩模本身未覆盖远山） |
| 05A 寒林 | bbox 75.1% | 枯枝为细线结构，密度平滑后 <0.12 被滤除；精修贴到岩壁/外框而非枝干 | ❌ 不可产出（线状结构，面状密度门不适用） |

### 9.4 结论与集成设计（v1.0 已落地）

1. **密度精修模式**：弥散门拒绝的层进入精修通道
   `refined = rejected_mask ∩ (D_s>floor) + 形态学`，精修后再过弥散门，
   通过则产出（`semantic_coverage.produced[].source="density_refined"`，floor 进披露）。
   **04A 峭壁已集成并端到端验证产出（bbox 4801×4282）**。
2. **密度带通道（v1.0 新增）**：DINO 完全未命中的纹理类（如 03 水波）直接用
   `region × 密度区间` 产层（`band_mask()`），source=density_band。**03 已验证产出**。
3. **04D 远山**：—— **v1.0 实测结论：本图不可自动提取**。裁图确认远山为极淡灰晕，
   亮度与金地同量级、色相也无显著差异（B−R 采样三区无区分度）；
   密度带尝试产出的层落在金地过渡区（错误层，已回滚配置）。
   维持 SAM 尝试 + 弥散拒绝 + manifest 披露。需更高对比度扫描件或人工定位。
4. **05A 寒林（线状结构）**：三种方法实测（平滑 D 精修 / 原始 D 高 floor / 小核形态学）
   均无法收敛（bbox 仍 ~74%）。面状密度门不适用。候选：规则引擎 Frangi 骨架流
   产线状层，或 WebUI 半自动笔刷 —— 独立工作项。
5. **实例拆分（v1.0 新增）**：`instance_split` 类按 DINO 框独立成层；
   质量门对实例层面积预算放宽 `INSTANCE_BUDGET_FACTOR=3`（单个体不按整类衡量），
   弥散门照常。雁群已产出 2 个单实例层。
6. rejected_masks 在 provider 中留存（`provider.rejected_masks`），供精修与调试。
7. **校准工具**：`tools/calibrate_density_bands.py` 输出九宫格+自定义区域的密度分布与
   推荐带（p60→p95），把"手调阈值"降级为"工具推荐 + 人工确认"。

## 10. 区域先验 SAM 通道（2026-09-12 P1/P2/P3 攻坚结论）

### 10.1 通道定义（第 4 条产层通道）

preset 给语义类配置 `region`（归一化 x0,y0,x1,y1）+ `region_boxes` 时，
**绕过 DINO 粗框**（弱语义类的粗框会让 SAM 输出全画布弥散掩模），
在区域内采样 2-3 个子框分别预测，取**面积最小的合理候选**（局部对象优先）合并。
产出仍走质量门 / 弥散门 / semantic_coverage（`source="region_sam"`）。

代码：`GroundedSAMProvider._infer_region_sam()` + `segment_objects` 2.5 段集成。

### 10.2 三类攻坚最终结论

| 类 | 尝试方案 | 结果 |
|---|---|---|
| **05A 寒林** | ① Frangi 线状簇（与树位置先验重叠仅 12-14%，响应多为金地颗粒噪声）② SAM 密集小框 44 框（bbox 68.5% 仍弥散）③ 密度精修（细线被平滑稀释）④ **区域先验 SAM** | ✅ **④ 成功**：region=[0.36,0.25,0.76,0.80] → bbox **75.1%→21.6%**，掩模精确贴合中央 5-6 棵枯树的树冠枝干 |
| **04B 平渚** | ① prompt 迭代（DINO 未命中）② **区域先验 SAM** | ✅ **② 成功**：region=[0.26,0.56,0.80,0.90] → 2176×628 bb17.5%，覆盖中央枯树下的横向坡岸/沙洲 |

### 10.3 关键洞察
