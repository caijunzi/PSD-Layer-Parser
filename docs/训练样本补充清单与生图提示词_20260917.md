# 训练样本补充清单与 AI 生图提示词（2026-09-17）

> 目的：为 T1 材质家族分类器（`tools/train_material_classifier.py`）补齐训练语料。
> 使用方法：提示词可直接粘贴到豆包/MJ/SD 等生图工具；按"变量矩阵"逐项替换批量生成；
> 生成的图按家族放入 `inputs_training/<家族>/`，**文件名不要含"AI"字样标注来源**——
> 来源记录用 `inputs_training/<家族>/_来源.csv`（文件名,来源=生成/实拍,工具）。

## 二、需新增的品目类别（含理由与生图提示词）

以下 9 类是**现有 8 类训练体系完全缺失**、但用户上传中高概率出现、且当前规则判别器
会**明确误判**的品目。P1 = 高频误判（最优先），P2 = 拒识质量（负样本），P3 = 织物细分。

### P1-1 书法作品（纯字画，无绘画内容）

- **为何必要**：宣纸底 + 墨字特征与"宣纸水墨"高度重叠，当前会**误判为宣纸水墨**并
  推荐水墨 preset——但书法图没有画心可分层，语义分割（山/石/雁）全部空转。
  独立成类后，推荐器可提示"书法作品"并建议专用处理路径（如只做题跋/印章分割）。
- **提升点**：覆盖率（新增一整类用户高频素材）＋ 准确率（把"宣纸水墨"的假阳性挪走）。

**基础提示词**：
> 中国传统书法作品高清照片，宣纸本竖幅立轴，毛笔行书书写唐诗一首，字距行气错落，
> 墨色浓淡枯润有致，钤盖朱红引首章与名号落款印，纸面可见天然纤维纹理与轻微做旧黄斑，
> 自然光从左上方入射使墨迹产生轻微立体反光，正面平视拍摄，作品居中占画面 80%，
> 背景为深灰色哑光纯色。

**变量矩阵（批量替换生成 20+ 张）**：

| 维度 | 取值 |
|---|---|
| 书体 | 行书 / 草书 / 楷书 / 隶书 / 篆书 |
| 形制 | 竖幅立轴 / 横幅手卷 / 册页 / 扇面 |
| 内容 | 唐诗 / 对联 / 心经选段 / 题画诗 |
| 光照 | 左上自然光 / 柔和顶光 / 侧逆光（突出墨层） |
| 背景 | 深灰纯色 / 深木桌面 / 展墙射灯 |

---

### P1-2 木刻版画（浮世绘 / 杨柳青年画 / 传统木刻）

- **为何必要**：平涂色块 + 硬边轮廓线的特征与工笔/屏风"描线"风格混淆；
  浮世绘与金地屏风同属日本美术，用户极易上传——当前会误判"金地屏风"或"绢本工笔"。
- **提升点**：把"日本美术"从"金地屏风"里拆出非屏风载体，显著降低旗舰族的假阳性。

**基础提示词**：
> 日本江户时代浮世绘木刻版画，歌川派风格，描绘东海道五十三次风景，
> 平涂色块与清晰木刻轮廓线，普鲁士蓝与赭石主色，纸面可见木纹肌理与手工拓印
> 的不均匀着色，边缘有装裱裁切痕迹，柔和漫射光均匀照明，正面平拍，背景米色纯色。

**变量矩阵**：浮世绘风景 / 浮世绘美人立姿 / 杨柳青年画娃娃 / 徽派木刻书籍插图 ×
自然光 / 漫射光 / 侧光 × 米色 / 深灰 / 木桌背景。

---

### P1-3 唐卡 / 宗教绘画

- **为何必要**：金底 + 浓彩 + 对称构图与"金地屏风"特征重叠，当前**必然误判金地屏风**；
  独立成类后可避免旗舰族被宗教画污染，且是潜在的独立处理品类（装裱与用印逻辑完全不同）。
- **提升点**：旗舰族准确率（挪走最强干扰源之一）。

**基础提示词**：
> 西藏唐卡绘画高清照片，布面矿物颜料，中央主尊坐像严格对称构图，金色勾线描边，
> 色彩浓烈饱和（朱砂红、石绿、群青），四周满绘经变故事与祥云卷草装饰，
> 上下装裱锦缎佛帘与彩燕，柔光箱均匀照明消除反光，正面平拍，背景深红纯色。

**变量矩阵**：主尊坐像 / 坛城曼陀罗 / 护法立像 × 红唐 / 黑唐 / 彩唐 × 柔光箱 / 自然光
× 深红 / 深蓝 / 展墙背景。

---

### P1-4 水彩画

- **为何必要**：纸本 + 透明淡彩特征落在"宣纸水墨"与"西洋绘画"的判定边界上，
  是当前规则器的**双族摇摆区**。独立成类可消除这组最不稳定的混淆。
- **提升点**：边界清晰化（混淆矩阵对角线质量）。

**基础提示词**：
> 欧洲水彩画原作高清照片，粗纹水彩纸纹理清晰可见，透明罩色与水渍晕染边缘自然，
> 描绘南欧小镇街景，留白处保留纸面本色，画纸四边有水彩胶带固定痕迹，
> 柔和自然光轻微侧入，15° 微俯拍摄，背景为白墙与木质画架。

**变量矩阵**：街景 / 花卉静物 / 海景 / 森林 × 俯拍 / 平视 / 45° × 白墙 / 木桌 / 画架背景。

---

### P1-5 素描 / 速写（铅笔 / 炭笔）

- **为何必要**：单色灰阶 + 纸底与水墨的灰阶特征重叠，但笔触机理（排线/擦痕）完全不同；
  当前会误判"宣纸水墨"。独立成类后为"素描 preset"（细线提取而非色彩分层）铺路。
- **提升点**：灰阶类素材的辨析度。

**基础提示词**：
> 炭笔人物速写原作高清照片，素描纸纹理与橡皮擦痕清晰可见，排线笔触明确，
> 单色灰阶明暗层次丰富，画中有炭粉飞溅的细小颗粒，侧光突出纸张肌理的立体感，
> 轻微俯拍 10°，背景为深色木画桌。

**变量矩阵**：人物速写 / 静物素描 / 石膏像 / 风景写生 × 侧光 / 顶光 / 自然光 ×
木桌 / 画板 / 纯灰背景。

---

### P2-6 摄影照片·风景（负样本）

- **为何必要**："其他"拒识类当前为 0——没有负样本，分类器**学不会说"我不知道"**，
  未识别品类的提示卡永远无法被模型置信。风景照是用户最可能上传的无关图。
- **提升点**：拒识准确率（这是"未知品类提示卡"功能的模型基础）。

**基础提示词**：
> 高清风光摄影照片，全画幅相机 RAW 直出质感，雪山湖泊日出黄金时刻，
> 真实景深与自然透视，可见镜头暗角与细腻噪点纹理，无任何绘画笔触或艺术滤镜，
> 广角构图，直方图动态范围宽广。

**变量矩阵**：雪山湖泊 / 海岸森林 / 草原星空 / 城市天际线 × 黄金时刻 / 蓝调时刻 / 正午
× 广角 / 长焦压缩。

---

### P2-7 摄影照片·人像（负样本）

**基础提示词**：
> 高清人像摄影照片，85mm 定焦浅景深，真实皮肤纹理与发丝细节，自然室内窗光，
> 背景柔和虚化，无插画风、无赛璐璐感、无描线——严格写实摄影质感。

**变量矩阵**：室内窗光 / 户外逆光 / 影棚三灯 × 半身 / 全身 / 特写。

---

### P2-8 数码插画（厚涂 / 二次元，负样本）

**基础提示词**：
> 商业数码插画，Procreate 厚涂风格与赛璐璐混合上色，二次元角色全身立绘，
> 可见明显数位板笔触与图层光影，纯色渐变背景，均匀屏幕光，无纸纹无颗粒，
> 画面呈现纯数字媒介特征。

**变量矩阵**：角色立绘 / 场景概念图 / Q 版 × 厚涂 / 赛璐璐 / 扁平风 × 暖色 / 冷色背景。

---

### P2-9 3D 渲染图（负样本）

**基础提示词**：
> Blender/Octane 三维渲染图，PBR 物理材质，产品级三点布光，可见环境光遮蔽
> 与真实反射，超写实室内场景，纯色背景，无手绘笔触无纸纹。

**变量矩阵**：室内建筑 / 产品静物 / 角色渲染 × 写实 / 风格化 × 冷暖布光。

---

### P3-10 织物族扩样（现有两类内部扩充，参数化模板）

**织物壁布_实物照**（当前 3 张 → 需 12+）：
> 墙布/面料实物样品高清照片，{材质：棉麻交织/真丝提花/短绒雪尼尔}，
> {纹样：大马士革团花/几何回纹/花卉藤蔓/细条纹}，{色调：灰米/墨绿/砖红/藏蓝}，
> {拍摄：正面平拍/45° 斜摄/微距特写/斜摄带卷边折角}，
> {光照：自然窗光/单侧光/柔光箱}，背景为桌面或展墙，画面体现织物经纬肌理。

**织物壁布_数码稿**（当前 1 张 → 需 14+）：
> 无缝四方连续平铺纹理设计图，{纹样：大马士革/几何/花卉/格纹}，
> {色调}，满幅重复无接缝无透视无阴影，均匀照明，正面平视，2:1 或 1:1 构图。

### 现有 8 类的补量模板（同一模板换名词即可）

以金地屏风为例（其余类把主体词换掉）：
> {日本江户金地六曲屏风}高清照片，{金箔底/墨绘寒林芦雁/朱印题跋/绫边装裱}，
> {构图：全景/右翼局部/画心特写}，{光照：柔和漫射/单侧自然光}，
> {背景：深灰展墙/木桌}，正面或微俯拍摄。

每类按 构图 3 × 光照 3 × 局部 2 = 18 张左右即可达标。

## 三、来源纪律（影响泛化质量，务必遵守）

1. **AI 生成与实拍/扫描混合**：每族建议 生成:实拍 ≈ 7:3 起步（当前全部为生成图，
   全生成训练集会让分类器学到"生成痕迹"而非"材质特征"）；
2. **来源必须记录**：`inputs_training/<家族>/_来源.csv`（文件名, 来源, 工具）——
   训练脚本未来会用它做分布平衡；
3. **拒识类（P2）允许 100% 生成**，但要求覆盖 4 种不同媒介质感；
4. 任何族补齐后先跑 `python tools/train_material_classifier.py --validate-only`
   看清单，再跑 `--train` 出对比报告。
