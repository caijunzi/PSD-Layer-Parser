## 二、机制归因（为什么不必再写新算法）

现有四条**品类可选**通道已覆盖绝大多数"未命中/被拒"类，均为已接线、已实证：

1. **区域先验 SAM**（`region` + `region_boxes`）→ 解决 DINO 对小尺度/无边界的漏检（05A / 04B / 04C）；
2. **密度精修通道**（`density_refine.classes[name].floor`）→ 救回被弥散门误拒的内容层（04A）；
3. **密度带通道**（`density_band_classes[].density_min/max`）→ 解决纯纹理类无对象边界的问题（03）；
4. **弥散门 + 豁免名单**（`MAX_BBOX_AREA_RATIO` + `is_bbox_exempt`）→ 防止雾化污染（正确拒绝 04D）。
