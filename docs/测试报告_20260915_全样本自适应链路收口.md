## 4. CBR 证据判定

本轮不以 PSB 相同作为 CBR 唯一证据。对 4 个命中样本均核对了：

1. repeat 日志存在 `CBR 命中（白名单通过）`；
2. episode 的 `notes` 含 `cbr_reused=1`；
3. episode 保留 `artifact` 和最终检测；
4. 案例来自同一产品线并通过严格准入，因此进入隔离 `index.pkl`。

本轮案例的 `auto_tune` 顶层键存在，但 `global_percentiles`、`regions` 为空，`density_bands` 为空。因此日志中的 `cbr_applied=false` 是准确的：CBR 确实命中并复用案例标记，但没有可应用的结构化调优参数。不能把它表述为“结构化参数已复用”。

## 5. Episode、反馈与学习验证

每个 case 产生 2 条 episode，对应 cold 和 repeat；共 18 条。每条记录均有：

- `artifact` / `audited_artifact`
- `output_mode`
- `dino_detections` 和 `detections`
- `audit_full` 原始完整报告及兼容摘要 `audit_8d`
- 指纹 embedding

每次运行都生成隔离的反馈队列和学习任务记录：

- `pending.jsonl`：每个 case 4 条反馈记录；
- `learning.jsonl`：每个 case 6 条学习记录；
- 18/18 学习任务状态为 `completed`；
- 18/18 均有非空影子建议；
- 无 `learning_error`。

严格准入行为符合设计：

- 通过 8 维审计的 episode 进入 CBR index；
- 失败、缺字段或未核验的 episode 不进入 index；
- DESIGN 线豁免第 ⑦ 维，PLATE 线第 ⑦ 维仍为必需维度。
